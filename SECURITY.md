# Security Policy

## Supported Versions

Use the latest version of this project to ensure you have the latest security patches.

## Reporting a Vulnerability

We take the security of our software seriously. If you find a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to security@example.com.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.
